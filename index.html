1. 設計原則

Module言語は静的手続き型スクリプト言語であり、メタシステムプログラミングと数値計算に特化しています。その安全性・記述性・性能のバランスを追求し、予期せぬシステムエラーをコンパイル前の型チェックによって排除します。

2. スタートアップ

Module言語はコンパイルを必要とするので、以下の手順で準備を進めます。

  1. ここをクリック (ファイルサイズ: 12MB) する。
  2. ダウンロードが完了するまで待つ。
  3. ダウンロードしたフォルダーを解凍し、以下のファイルが同封されているか確認する。
    • PROGRAM/
      • main.mod
      • utils.mod
    • STDLIB/
      • ALGORITHM.txt
      • GRAPH.txt
      • MATH.txt
      • NETWORK.txt
      • SYSTEM.txt
      • ERROR.txt
    • modc.exe

コードエディター (VS Codeや公式エディター) でmain.modを開き、以下のコードを入力してください。改行は文の区切りで、インデントは読み飛ばされます。

print("Hello, world")

コンパイラーmodc.exeのコマンドラインで:c main.modを実行すると、標準ライブラリ (./STDLIB/*.txt) → 宣言ファイル (./PROGRAM/utils.mod) → 定義ファイル (./PROGRAM/main.mod) の順序でファイルを読み込み、アルゴリズム到達不能なコードの削除および定数畳み込みの最適化を行い、PROGRAMフォルダーにmain.asmファイルが生成されます。また、:r main.modでコンパイルと実行を一括にすることができます。

4. 識別子

数字以外で始まり、スペースで区切られ、大文字と小文字の区別がある文字または文字列を識別子 (トークン) と呼びます。

既定の識別子
識別子意味識別子意味
bool論理型def関数宣言
int整数型tef名前空間宣言
float実数型if分岐
char文字型loop反復
wcharワイド文字型endスコープ終了
var変数宣言break反復終了
const定数宣言continue反復継続
static静的メモリ宣言import導入宣言
new動的メモリ宣言

他の識別子は規定されておらず、ユニコード文字かつ先頭文字から10文字を有効範囲としています。識別子を使うときは、未定義動作防止の観点から初期化されないとコンパイル時エラーとなります。ただし、値渡し (書き換えは生じないものの、比較的大きな値には複製の時間で非効率) になります。

4.1 可変な識別子の宣言 (変数)

使用しなくなった時点で解放されます。

var type identifier = expression
var int age = 20

4.2 不変な識別子の宣言 (定数)

コンパイル時に置き換えられます。

const type identifier = expression
const int lifespan = 80

/- 代入はコンパイル時エラー : lifespan = 90 -/

4.3 識別子とメモリの関係

プログラム開始から終了までメモリを保持する機能、および任意のスコープのみにメモリを保持する機能があります。スコープとは識別子を参照できる範囲です。

4.3.1 静的メモリ宣言 (スタック領域)

プログラムの開始から終了まで、メモリを保持する機能です。これは、実行中もしくは静的にメモリを確保するとも意味します。

/- 不変静的メモリ宣言 : 初期化後変更不可能 -/
const static identifier = [type, type, ...]{expression, expression, ...}

/- 可変静的メモリ : 初期化後変更可能 -/
var static identifier = [type, type, ...]{expression, expression, ...}

右辺の[]は配列の型配置、{}はその要素を意味しています。また、その配列の要素として配列を代入することもできます。

var static calmem = [int<16>, float<32>[3]]{2, {0.67, 0.23, 0.45}}

/- 以下と同じ -/
var int<16> c_1 = 2
var float<32>[3] c_2 = {0.67, 0.23, 0.45}

4.3.2 動的メモリ宣言 (ヒープ領域)

任意のスコープのみ、メモリを保持する機能です。これは、実行時もしくは動的にメモリを確保するとも意味します。しかし、確保の失敗があった場合はERRORライブラリリファレンスで仕様を確認してください。

/- 不変動的メモリ宣言 : 初期化後変更不可能 -/
const new identifier = [type, type, ...]{expression, expression, ...}

/- 可変動的メモリ宣言 : 初期化後変更可能 -/
var new identifier = [type, type, ...]{expression, expression, ...}
var int length = input()
var new buffer = [char[length]]{{0, 67}}

ただし、type (初期型) と右辺のexpression (初期値) は、型・配列・初期化規則に従い、宣言ごとにstaticまたはnewの一方だけを指定します。

5.1 論理型

真または偽を示す型です。偽として扱われるものは整数0の他に、空配列、空文字列、無効なメモリアドレスです。厳密に1ビットで表現したい場合、定義演算子でTRUE := 1もしくはFALSE := 0としてください。

5.2 整数型

正数と負数があり、負数は正数の 2 の補数です。以下の整数を表現することができます。

5.3 実数型

IEEE 754で定義されている、32ビットの単精度 (符号1ビット、指数部8ビット、仮数部23ビット) または64ビットの倍精度 (符号1ビット、指数部11ビット、仮数部52ビット) の実数を扱います。特別な値は下の表を参考してください。

5.5 配列型

固定長 (スタック方式) で、型名のあとに[length]をつけます。配列の宣言された長さと初期化時の要素数が異なる場合や空の配列 ({})、多次元配列の深さと各lengthが異なる場合は、コンパイル時に指定された型の初期値で埋められます。配列の要素にアクセスするにはidentifier[index]を使います。

/- 可変配列 : 要素が可変 -/
var type[length] identifier = {expression, expression, ...}

/- 不変配列 : 要素が不変 -/
const type[length] identifier = {expression, expression, ...}

head (array[0]) を指定する以外に、tail (array[-1]) も指定することができます。その関係式はarray[-n] = array[len(array) - n]で、コンパイル時に正のインデックスへ展開されます。

const char[5][5] string = {"He", "is", "smart"}
const char word = string[-2][1]
print(word)
s

5.6 参照型

参照型は変数や定数、関数、配列のアドレスを示す型で、アドレスは必ず参照先の変数で操作します。アドレスを保持する識別子を必要とし、その戻り値の16ビット正符号整数をアドレスとします。

/- 可変参照 -/
var int identifier = ref expression

/- 不変参照 -/
const int identifier = ref expression
const int value = 20
var int p = ref value

/- 参照の初期化 -/
var int q = ref 0

/- コンパイル時エラー : 0以外の即値 -/
/- const int r = ref 20 -/

print("$(p)\n$(q)")
0x7fff5fbff8ac
0x000000000000
const char[] g = "Hello, world"

/- 文字列 "Hello, world" を指す -/
var char[] s = ref g

/- 文字を指す -/
var char p = ref s

print(p += 1)
e
アドレス演算意味
p += nアドレスをxのバイトサイズ ⨯ n進む
p -= nアドレスをxのバイトサイズ ⨯ n戻る
p + n = expressionpからn進んだアドレスにexpressionを代入する
p - n = expressionpからn戻ったアドレスにexpressionを代入する

5.7 タプル型

複数の型の値を順番通りにまとめて保持できる変更不可な配列型で、必ず定義演算子を使います。要素へのアクセスはidentifier[index]で可能です。

identifier := (expression, expression, ...)
/- 年齢、名前、売上前年比 -/
person := (26, "Tanaka", 1.8)
print(person[1])
Tanaka

名前空間宣言を使えば、以下のように書き換えることができます。

tef DATA
    int,
    char[],
    float
end

const DATA person = {26, "Tanaka", 1.8}
print(person[2])
1.8

6.3.3 キャスト演算子 :

自動的に型変換は行わないため、異なる型に変換する場合に使います。変数にのみ使用することができ、定数に対してはコンパイル時エラーになります。

identifier : type
const char c = "A"
const wchar w = c : wchar

6.3.4 シフト演算子 << >>

整数型の値どうしを計算します。

/- 左シフト -/
identifier << identifier

/- 右シフト -/
identifier >> identifier
const int result = 40 << 3

6.3.5 オーバーレイ演算子 ~

新しく確保したメモリに値をコピーしたり、参照型を付け替えることをしません (ゼロ・リロケーション) 。値がオーバーフローした場合の演算結果は破棄されません。別の型へのキャストはコンパイル時エラーです。

~ identifier
var int<16> x = 40000
const int y = ~x

6.3.6 エイリアス演算子 &

既に宣言されている変数を別名として確保します。これは参照渡しになります。

&identifier
var char[10] greeting = "Morning"
print("$(greeting)\n")

var char[] g = &greeting
g = "Evening"

print("$(greeting)\n")
print(g)

Evening
Evening

/- 型の明示付き定数 -/

7. 制御文

7.1 if

条件が真の場合にブロック内の命令を順に実行し、偽の場合は実行されずに次の命令に進みます。

if condition
    body
end
const bool x = 1
const bool y = 0
if x and y is 1
    print("No")
end
if x or y is 1
    print("Yes")
end
Yes

7.2 loop

命令の繰り返しを実行します。繰り返し中断には予約語のbreak、繰り返し再開には予約語のcontinueを使います。

loop
    body
end
var int i = 0
var int<u16> result = 0
const int[] list1 = {1, 4, 3, 6}
const int[] list2 = {2, 3, 7, 1}
/- 内積の計算 -/
loop
    if i > sizeof(list1)
        break
    end
    result += list1[i] * list2[i]
    i += 1
end
print(result)
41

8. 関数

関数はコンピュータに対する命令 (アルゴリズム) の集合で、型から型へ変換する単一入力・単一出力を原則としています。定義のときは仮引数、呼び出すときは実引数を必要とします。非単一の入力および出力には、タプル型を使います。

8.1 関数の呼び出し

コンパイラ側で標準提供されている関数です。宣言なしで直接呼び出すことができます。

8.1.1 input関数

標準入力を受け取って値を返します。

input() -> int[]

8.1.2 print関数

指定された値や式の結果を標準出力に印字します。行末に改行文字\nは挿入されません。

print(expression) -> const int

8.1.3 len関数

渡された配列や文字列の要素数（長さ）を整数で返します。

len(expression) -> int

8.1.4 sizeof関数

指定された識別子や式の型が使用するメモリ領域のバイト数を返します。

sizeof(expression) -> int
a

8.1.5 typeof関数

指定された識別子の型を返します。

typeof(expression) -> type
if typeof(4.1) is float
    print("float")
end
float

8.1.6 alignof関数

指定された型に適用されるアライメント（バイト単位）を返します。

alignof(expression) -> int
a

8.2 関数の宣言

プログラマが自由に関数を作成することができます。引数パラメータに対してidentifier = expressionとデフォルト値を設定することができます。

def identifier type -> type
/- タプル型を受け取り、値 (実数型) を返す関数 -/
def multiply (float, float) -> float<64>

/- 値 (16ビット整数型) を受け取り、配列型を返す関数 -/
def retArr int<16> -> char[]

/- タプル型を受け取り、タプル型を返す関数 -/
def calculate (int, int) -> (int, int)

def identifier type -> const typeのように戻り値がconstならば、その関数がインライン化されます。

8.3 関数の定義

宣言された関数に対して、その本体を定義します。戻り値として指定したパラメータに値を代入した時点で、関数のブロック全体から脱出します。一度も代入されなかった場合はコンパイル時エラーになります。

identifier parameter -> parameter
    body
end
def div (int, int) -> int

div (x, y) -> z
    if y is 0
        z = 0
        /- パラメータ z に代入されると同時に値が返される -/
    end
    z = x / y
end
def calculateA (int, int) -> (int, int)
def calculateB (int, int) -> (int, int)

calculateA in -> (a, b)
    /-
      仮引数 in は (int, int) のタプル型
      戻り値の a と b は仮引数のため、代入可能 (初期化原則より)
    -/
    a = in[0] + in[1]
    b = in[0] * in[1]
end

calculateB (in_a, in_b) -> (a, b)
    /- 仮引数 (in_a, in_b) は、in_a と in_b の整数型 -/
    a = in_a + in_b
    b = in_a * in_b
end

const int sumA = calculateA(1, 2)[0]
const int sumB = calculateB(1, 2)[0]
const int mulA = calculateA(1, 2)[1]
const int mulB = calculateB(1, 2)[1]
print("SumA : $(sumA)\tSumB : $(sumB)\nMulA : $(mulA)\tMulB : $(mulB)")
SumA : 3    SumB : 3
MulA : 2    MulB : 2

newで動的に確保したメモリを参照型で返す場合、コンパイル時に静的メモリ宣言に変えられます。

8.4 関数のオーバーロード

関数の識別子が複数あり、定義が単数の場合はオーバーロードと呼ばれます。実引数の型および数に対応する関数が呼び出されます。

def sum (int, int) -> int

/- 引数の数が異なる場合 -/
def sum (int, int, int) -> int

/- 引数の型が異なる場合 -/
def sum (float, float) -> float

sum (a, b, c = 0) -> d
    d = a + b + c
end

9. 名前空間

識別子の衝突を防ぎ、構造を整理するために使用します。名前空間に同名が存在するときは、一つに定まっていないためにコンパイル時で未定義エラーです。

tef identifier
    body
end
import MATH
tef complex
    float x,
    float y
    def norm (float, float) -> float
end

norm (x, y) -> z
    z = MATH::sqrt(x ^ 2 + y ^ 2)
end

const float complex::x = 1.2
const float complex::y = 3.8

print(complex::norm(complex::x, complex::y))
