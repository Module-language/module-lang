Moduleとは

安全性・記述性・性能のバランスを追求したプログラミング言語です。Visual Studio Code (通称VS Code) などの環境構築を必要とせず、

  • 公式エディタ
  • コンパイラ
の二つのみで編集ができます。コンパイラは ここから 入手してください。

従来の課題Moduleの考え方
メモリ安全コンパイラが安全性を補助する
記述量必要最低限の構文で書ける
学習コスト初学者でも理解しやすい設計

コードの基本構成

基本的に

  1. var / const / def 修飾子で宣言
  2. main ブロック内で実行したい処理を記述
  3. その間に定義を書く

という流れです。コードを上部から読んだとき
宣言 → 定義 → 実行
となります (この順は必須でない) 。コンパイラは宣言を優先的に定義し、その次にユーザーの定義を最適化します。

Hello, world!を出力する

def print(str) -> str const message : str = "Hello, world!" print : x -> y { y = output(x) } main: { print(message) }

例外処理はありません (エントリーポイントとなる main 関数が -1 という値を返します)。

このパートでは、コードを書く際の基本となる情報を整理します。

コメント

コード中にメモを残す場合、定義されていない文字が含まれているとコンパイル時警告になります。安全にコメントを書く方法は以下の2通りです。

構文

// コメント /- コメント -/

識別子と予約語

識別子

識別子とは、予約語以外の以下の規則を満たす語句のことです。

  • ユニコード文字である
  • 数字で始めてはいけない
  • 大文字と小文字は区別される

予約語

予約語は、既に定義されている語句 (全20個) のことです。

voidboolintfloatstr
varconstdeftefif
andornottruefalse
isjumpimportnewwhere

式と文

式は命令を含まないもの、文は命令を含むものと定義します。文は改行区切りであり、他言語にみられる行末セミコロンは必要ありません。また、インデントはコンパイル時に読み飛ばされるので、プログラマーは自由にタブをいくつか置くことができます。変数とはアドレスに付与した識別子、定数とは変数を変更不可にした識別子のことです。ただし、それらは必ず初期化しなければなりません (未定義動作の防止)。

変数の宣言

var name : type = value

定数の宣言

const name : type = value

値20を、(符号付き)整数型で宣言します。

var age : int = 20
const lifespan : int = 80

型

型とは、起点のアドレスから何バイトの領域を使うかとそのビット列をどう解釈するかを表したものです。基本型、構造型、直接メモリを指し示す参照型、プログラマが定義する特殊型に分割されます。

基本型 (Fundamental Type)

基本型は空型、論理型、整数型、浮動小数点数型、文字列型に分けられ、これらをいくつか組み合わせて新たな型を生成することができます。

参照型 (Reference Type)

参照型は変数や定数、関数を指し示す型のことで、予約語の at を使います。

name : type = at variable

特に関数は以下のように記述します。

name : type -> type = at func

関数を参照する場合、type -> type の記述の仕方次第で安全に関数オーバーロードができます。

特殊型 (Custom Type)

特殊型はプログラマが自由に型を生成でき、予約語の tef (グローバル型) と new (ローカル型) を使います。

tef identifier typedef
name : new identifier typedef = value

特にnewは、identifierの部分を省略することがきます。これはローカルなゆえに匿名だからです。

a

var a:int = 19 var b:int = 1 def add(int, int) -> int const f : (int, int) -> int = at add add : (x, y) -> z {z = x + y} main : { output(f(a, b)) }

大切なことをもう一度述べます。

  • アドレスとは、値 (データ) が配置されているメモリ上の番号
  • 変数とは、アドレスに付与した名前 (識別子ともいう)
  • 型とは、起点アドレスから何バイトの領域をどう解釈するかを表したもの
  • 値とは、アドレスの領域に書き込まれているデータ (ビットパターン)
です。

関数

関数はコンピュータに対する命令(アルゴリズム)の集合です。コンパイラは

  1. 到達不能コード削除
  2. インライン展開
  3. 定数畳み込み
の順で最適化を行います。

関数の宣言

def func-name(type1, type2, ...) -> return-type

関数の定義

func-name : (param1, param2, ...) -> return-param {
 statement
}

a

// 加算関数を宣言する
def add(int, int) -> int
// 加算関数を定義する
add : (x, y) -> z {z = x + y}
