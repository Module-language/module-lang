Moduleとは

グローバル空間での直接実行はできません。

安全性・記述性・性能のバランスを追求したプログラミング言語です。その特徴から思考型プログラミング(Thought-Oriented Programming) と呼ばれます。Visual Studio Code (通称VS Code) などの環境構築を必須とせず、

  • 公式エディタ
  • コンパイラ
の二つのみで編集ができます。コンパイラは ここから 入手してください。

従来の課題Moduleの考え方
メモリ安全コンパイラが安全性を補助する
記述量必要最低限の構文で書ける
学習コスト初学者でも理解しやすい設計

コードの基本構成

基本的に

  1. var / const / def 修飾子で宣言
  2. main ブロック内で実行したい処理を記述
  3. その間に定義を書く

という流れです。コードを上部から読んだとき
宣言 → 定義 → 実行
となります。コンパイラは宣言を優先的に定義し、その次にユーザーの定義を最適化します。

エラーの扱い

  • 型エラー：異なる型である場合
  • ランタイムエラー：実行時に予期しないプログラムが読み込まれた場合
  • 構文エラー：構文に合致しない場合
  • 未定義エラー：未定義の場合

危険度レベル条件
1軽微 (警告 -> 実行可能)
2悪用可能性あり (権限昇格で実行可能)
3極めて危険 (実行拒絶)

Hello, world!を出力する

// 宣言 def print(str) -> str const message : str = "Hello, world!" // 定義 (output関数は文字列型を入力、文字列型を出力する) print : x -> y { y = output(x)} // 実行 main : { print(message) }

例外処理はありません。エントリーポイントとなる main 関数は通常 0 を返しますが、例外があれば -1 を返します。No exception with ease to write.

はじめに

このパートでは、コードを書く際の基本となる情報を整理します。

コメント

コード中にメモを残す場合、定義されていない文字が含まれているとコンパイル時警告になります。安全にコメントを書く方法は以下の3通りです。

構文 // 単行コメント /- 複行コメント -/ /< ドキュメントコメント >/

識別子と予約語

識別子

識別子とは、予約語以外の以下の規則を満たす語句のことです。

  • ユニコード文字である
  • 数字で始めてはいけない
  • 大文字と小文字は区別される

予約語

予約語は、既に定義されている語句 (全20個) のことです。

voidboolintfloatstr
varconstdeftefif
andornottruefalse
isjumpimportnewwhere

式と文

式は命令を含まないもの、文は命令を含むものと定義します。文は改行区切りであり、他言語にみられる行末セミコロンは必要ありません。また、インデントはコンパイル時に読み飛ばされるので、プログラマーは自由にタブをいくつか置くことができます。変数とはアドレスに付与した識別子、定数とは変数を変更不可にした識別子のことです。ただし、それらは必ず初期化しなければなりません。

※ 未定義動作の防止の為、未初期化の変数/定数はコンパイル時エラーとなります

変数の宣言 var name : type = value
定数の宣言 const name : type = value
値20を、(符号付き)整数型で宣言します。 var age : int = 20 const lifespan : int = 80

型

型とは、起点のアドレスから何バイトの領域を使うかとそのビット列をどう解釈するかを表したものです。基本型、構造型、直接メモリを指し示す参照型、プログラマが定義する特殊型に分割されます。

基本型 (Fundamental Type)

基本型は空型、論理型、整数型、浮動小数点数型、文字列型に分けられ、これらをいくつか組み合わせて新たな型を生成することができます。

空型

値を返さない関数や、明示的に何も存在しないことを示す型です。

空型 name : void = value

論理型

真 (true) または偽 (false) を表す1バイトの型です。ビット演算および論理演算に使用されます。

論理型 name : bool = value

整数型

負数は2の補数として扱われます。二進数 (0bYYYY...)、十進数 (YYYY..., 0dYYYY...)、十六進数 (0xYYYY...)を表現することができます。

整数型 name : int = value

浮動小数点数型

精度に応じた単精度 (32bit) / 倍精度 (64bit) 浮動小数点数を扱います。内部形式はIEEE 754の規格に従っています。指数 (YY...eYY...) を用いて表現することができます。

浮動小数点数型 name : float = value

文字列型

UTF-8エンコーディングされた文字の配列を扱う型です。ダブルクォーテーション記号 (") で囲みます。文字のコードポイントには、シングルクォーテーション記号 (') で囲みます。

演算意味例
"string" + "string"2つの文字列を結合する"Hello, " + "world"
"string" * integer文字列を回数分繰り返す"Ha!" * 3
文字列型 name : str = value

また、直接印字されない文字 (制御文字) や文字の重複を避ける (エスケープシーケンス) も存在します。

制御文字意味
\'シングルクォーテーション記号
\"ダブルクォーテーション記号
\\バックスラッシュ記号
\0終端文字
\n改行
\s空白
\t水平タブ

※ バックスラッシュは、Shift-JISでは円記号として表示されます。

構造型 (Structure Type)

集合型

数学の集合(ZFC)と同等の扱いです。クイックソートによって、重複排除を実現しています。

演算子意味使い方
+和集合{1, 2} + {3, 4}
-差集合{1, 2} - {3, 4}
&共通部分{1, 2} & {3, 4}
*冪集合{1, 2} * {3, 4}
^補集合^{1, 2}
構文 name : set = {v1, v2, ...} name : set = {v | Set-builderNotation}

空集合は {} 、部分集合は {{...}, ...} と書きます。インデックス外は空集合です。

配列型

配列の長さと配列の要素数が異なる場合や空の配列 ({})、多次元配列の深さと各 length が異なる場合は、コンパイル時に指定された型の初期値で埋められます。

構文 // 固定長配列 (スタック方式) name : type[length] = {v1, v2, ...} name : type[length][length] = {{v1, v2, ...}, {w1, w2, ...}} // 可変長配列 (ヒープ方式) name : type[] = {v1, v2, ...}
文字列を文字の配列として表現する const string : str[] = {"H", "e", "l", "l", "o"}

参照型 (Reference Type)

参照型は変数や定数、関数、配列を指し示す型のことで、at 演算子を使います。左辺値はアドレスなので、通常は符号なし整数です。関数を参照する場合、type -> type の記述の仕方次第で安全に関数オーバーロードができます。配列を参照する場合、その先頭から指します。

構文 // 変数や定数、配列を参照するとき name : type = at variable // 関数を参照するとき name : type -> type = at func // 参照先に代入 [name] = value
例 var a : int = 19 var b : int = 1 def add(int, int) -> int const f : (int, int) -> int = at add add : (x, y) -> z {z = x + y} main : { output(f(a, b)) }

重要点は

  • アドレスとは、値 (データ) が配置されているメモリ上の番号
  • 変数とは、アドレスに付与した名前 (識別子ともいう)
  • 型とは、起点アドレスから何バイトの領域をどう解釈するかを表したもの
  • 値とは、アドレスの領域に書き込まれているデータ (ビットパターン)
です。

特殊型 (Custom Type)

特殊型はプログラマが自由に型を生成でき、予約語の tef (グローバル型) と new (ローカル型) を使います。

構文 tef identifier typedef name : new identifier typedef = value

特に new は、identifierの部分を省略することができます。これはローカルなゆえに匿名だからです。

例 tef latice {int, int} z : new complex {float, float} = {0.0, 0.0}

オーバーフロー解決演算子

事前にオーバーフローが発生する可能性をコンパイラに知らせることができ、そのコンパイル時間の短縮します。

構文 variable :: type

サイズ指定演算子はバイト数、型指定演算子は型名そのものを扱います。

シフト演算子

構文 variable << shift variable >> shift

不等号演算子

構文 variable < variable variable <= variable variable > variable variable >= variable

等号演算子

構文 variable is variable

論理演算子

構文 variable and variable variable or variable not variable

推論演算子

構文 name := value

代入演算子

構文 name = value

限定演算子

コンパイル時に決定し、ランタイム中の制約を課すことができます。

構文 name : type = value where condition

whereによる制約条件は違反の場合のみ評価やその変数が存在する全期間における契約(制約が強い方が優先). コンパイル時にリテラルまたは定数が代入される場合は即座に条件と照らし合わせる.

例 var a : int = 2 where a > 0 or a <= 20

オーバーレイ演算子

より大きいアライメントを指定することで、新しく確保したメモリに値をコピーして、ポインタを付け替えることをしません(ゼロ・リロケーション)。なので、本体領域の低位ビットと拡張領域の高位ビットとして安全に値を参照できます。もし指定値がオーバーフローした場合、演算結果は破棄されず、一つ上のバイトサイズへ透過的にメモリを拡張します。別の型へキャストされる場合はコンパイル時エラーです。

構文 ref name = variable

解放演算子

確保したメモリ、使用済みのメモリを一括解放できます。

構文 delete name

解放演算子があるということは、ガベージコレクション(GC)の機能はありません。むしろ、実行時の圧倒的な軽さと予測しやすさを優先させています。

複合代入演算子

複合代入とは、代入演算子と他の演算子を組み合わせたものです。以下の種類があります。

演算子表記意味
加算代入演算子x += yx = x + y
減算代入演算子x -= yx = x - y
乗算代入演算子x *= yx = x * y
除算代入演算子x /= yx = x / y
冪乗代入演算子x ^= yx = x ^ y
剰余代入演算子x %= yx = x % y

制御文

if

式の条件が真 (true) の場合にブロック内の命令を実行します。逆に、式の条件が偽 (false) の場合は実行されずに次の命令があるアドレスに進みます。

構文 if (condition){ statement }

jump

a

構文 jump name name: statement

もしループを構成したいときは、ifとjumpを組み合わせて使います。

関数

関数はコンピュータに対する命令(アルゴリズム)の集合です。コンパイラは

  1. 到達不能コード削除
  2. インライン展開
  3. 定数畳み込み
の順で最適化を行います。

関数 (独立宣言) def func(type, type, ...) -> type
関数 (従属宣言) def func(param:type, param:type, ...) -> param:type { statement }
関数の定義 func : (param, param, ...) -> param { statement }
例 // 加算関数を宣言する def add(int, int) -> int // 宣言と定義を同時にできる def add(x:int, y:int) -> z:int { z = x + y } // 加算関数を別で定義する add : (x, y) -> z {z = x + y}

名前空間

識別子の衝突を防ぎ、構造を整理するために使用します。

構文 tef identifier definition

型を抽象化するには、以下のように書きます。これは一般的にラムダ型と呼ばれ、コンパイル時に指定された型で最適化されます。

構文 tef identifier[type] definition
例 tef complex[T]{ var a : float = 0.0 var b : float = 0.0 def norm(x:T, y:T) -> z:T { z = (x ^ 2 + y ^ 2) ^ 0.5 } } main : { // complex型の a を定数 r1 として参照 const r1 : complex(float) = a // complex型の b を定数 r2 として参照 const r2 : complex(float) = b // 変数 r1 と r2 のノルムを定数 result に確保 const result : complex(float) = norm(r1, r2) }

標準ライブラリ

コンパイラと同時にダウンロードされる、再利用可能なものです。その内容は熟練の公式開発者のみが毎年アップデートを行います。

構文 import library

名前空間に同名が存在するときは、一つに定まっていないためにコンパイル時で未定義エラーです。

MATHライブラリ

三角関数や対数などの数学専門ライブラリです。// "\pi"などの数学的リテラルはバックスラッシュで区別させる.

SYSTEMライブラリ

ファイルI/OやメモリなどのOS依存処理専門ライブラリです。#OSと#TIMEは#SYSTEMに統合. セルフホスティング性を保証するため. FILE filename = ""; filename:open()|:write()|export()|fixed()|close()|read()|restore()|check()|send()|receive() checkは暗号化チェック

NETWORKライブラリ

通信やHTTPリクエストなどのネットワーク処理専門ライブラリです。#WEBは#NETWORKに統合. 非同期処理.

GRAPHライブラリ

二次元や三次元の描画の描画バッファ専門ライブラリです。LaTeXのtikzライブラリの上位互換.

HPTライブラリ

一つのバケットで, Slot1(上層部=実データ用), Slot2(中層部=パリティ系用)、Slot3(下層部=転送用)に分割する. "mod hpt update", "mod hpt trace", "mod hpt rollback", "mod hpt history".

// 配列にバケットソートを適用する(各バケット(容量は3つ)はスタック(LIFO)状態)ことでメモリ管理しやすくする. インデックス優先探索で, エラー時のみ深さ優先探索の動的スイッチ. // 十六進数を扱うときは最低4つ必要だが, 3つに絞ることでクロストークおよびデータのはみ出し漏洩の防止を図る. // 最終的に溢れたデータは, バケット列構造とは異なるバケット(GB(Gabage Backet, ガベージバケット)と呼ぶ)で管理される. そのGBは配列になっているので, バケットと配列の組で高速性を叶える.

商用利用について

もし、Module言語で書かれたコードを商用にするとき、公式Githubに公開するか、公式審査宛に申請書を送信してください。もし、認証が未完了のままで商用扱いされているコードが発見された場合、直ちに差し止めの措置を行います。
